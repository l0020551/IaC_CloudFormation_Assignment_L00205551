# Real World Ops 
Run the scripts in the following order, VPC and Database need to be run only once, web and App `2_webNapp.yaml` updated for each new deployment.
Run in numeric order:
---
0.  `0_VPC.yaml`:  Deploy virtual private cloud
---
1.  `1_database.yaml`: Deploy database
---
2.  `2_webNapp.yaml`: Deploy Web and app layer.
